# Sync Claude

面向 **macOS Claude Desktop 4.29.0** 的原生小工具：保存官方账号、切换第三方 API 配置，让本机 Code 会话记录在切换后继续可见。

采用 SwiftUI + Foundation + macOS Keychain，不需要 npm、Python 或本地后台服务。官方订阅用量通过 Anthropic 用量接口只读查询。

## 下载与安装

从 [最新 Release](https://github.com/Chiiz0/Sync-Claude/releases/latest) 下载 `Sync-Claude-0.1.0-macos-arm64.zip`，解压后将 **Sync Claude.app** 放到 `/Applications` 或 `~/Applications`，再打开使用。请先安装并打开一次 Claude Desktop。

- 系统要求：macOS 13+；首版预编译包仅支持 Apple Silicon。
- Claude 原生数据写入适配：**Claude Desktop 4.29.0**。
- 发行包使用 Developer ID 签名、Apple 公证，并附带公证票据。
- 可用 Release 附带的 `SHA256SUMS` 检查下载文件：`shasum -a 256 -c SHA256SUMS`。

先将应用放在稳定位置，再添加 API 配置。凭据助手使用应用的绝对路径，后续移动应用需要更新助手路径。

## 使用

打开安装后的 **Sync Claude.app**。

1. 左侧自动显示 Claude 自带配置库中的 API 配置，选择后点击 **切换到此配置**。
2. 添加服务：点击 **添加 API 配置**，填写 Anthropic Messages API 地址、Key、认证方式及可选模型列表。保存后再选择该配置切换。API Key 写入 macOS 钥匙串；Claude 通过官方支持的 credential helper 获取它。首次使用 helper 时 Claude 可能要求执行授权。
3. 添加官方账号：点击 **添加官方账号**，完成登录、进入一次 Code，返回点击 **保存当前账号**。没有账号时，界面会引导完成登录和保存；只有识别到官方登录后才能保存。
4. 切换官方账号：直接在左侧“已保存的官方账号”中选择目标，点击 **切换到此账号**，也可从菜单栏切换。继续添加其他账号仍使用 **添加官方账号**，工具会先保存已有登录。
5. **后台归档**每 30 秒保留本地记录的版本；**同步并重载**把缺少的记录补入当前模式、当前登录账号已经存在的 Code 目录，再重开 Claude。通过本工具切换配置时会自动补入目标账号，不向旧账号目录写入。
6. **账户记录管理**显示各账户/组织的会话数、仅该目录可见的会话数和占用。空目录可直接 **永久删除空目录…**，不会新增恢复副本；有内容的目录使用 **清理所选…**，保留副本供恢复。两类目录分开选择，确认框会说明范围。当前官方/API 目录、有定时任务或远程会话的目录受到保护。此功能不删除共享会话正文、历史归档、登录快照或 API 配置。
7. **官方账户用量**集中查看已保存账号的五小时、周用量和服务返回的重置时间，无需切换当前 API。打开面板会刷新，保持打开时每 5 分钟刷新，时间按本机时区显示。失败保留上次数据并显示错误和更新时间；不把未知当成 0%，不在本地推算额度归零。登录过期需切回该账号进入 Code 后重新保存。
8. API 配置卡显示默认模型、1M 偏好及 Code/Cowork/Chat 保存的模型选择。**修复 1M 默认**仅针对当前启用且已声明支持 1M 的配置：启用原生 `modelPrefer1mContext`，清除标准版覆盖或已不在配置列表的旧模型选择，保留思考强度等偏好及已有会话。新加 API 时可显式声明所填模型支持 1M；自动发现时仅优先采用服务已声明的 1M 能力。
9. **配置别名**：选择任意官方账号或 API 配置，点击名称旁的 **编辑别名**，也可右键侧栏条目编辑。别名立即用于侧栏、菜单栏和官方用量面板；支持中文、空格和表情，最多 80 个字符。留空或点击 **恢复原名称** 可清除别名。别名保存在工具内，不改写 Claude 原生配置名称、登录信息或会话，也无需重启 Claude。
10. **删除配置**：侧栏右键选择 **删除官方账号…** 或 **删除 API 配置…**，核对确认框后删除。当前正在使用的配置需先切换。官方账号会从账号索引、快照目录、别名及用量缓存中移除；工具不会因自动保存而重新加入，需用户重新登录并明确保存。API 配置会从 Claude 原生配置库及别名中移除。Claude 若运行会正常重开。此操作不删除 Code 会话或共享归档，不注销官方服务端登录；操作备份及 API 钥匙串凭据仍保留，不能当作永久擦除，也不通过“账户记录管理”的目录恢复入口撤销。
11. **永久清除恢复副本**：“可恢复”和“已恢复的备份”中每项都有 **永久清除…**，也可使用 **永久清除本页全部副本…**。预览会统计文件数和大小，并核对是否完全为空。确认后，清除所选账户/组织目录的全部恢复版本（包括此前恢复过的版本）及关联操作备份中的目录内容，同时移除旧索引中的对应条目；不为已删除内容重新生成备份。操作日志只留下清除标记。不会删除已重新建立的原目录、其他账户目录、共享会话正文或历史归档，因此不等于把某段会话从整台电脑彻底擦除。清除副本无需重启 Claude；直接删除原空目录会正常重开 Claude。

账号首次登录、MFA、验证码及过期凭据重新认证仍需用户完成。新账号首次进入 Code 后才产生可用账户目录，首次需要再点一次“同步并重载”。

### “不用手动退出”如何实现

工具自动执行：检查会话进程 → 正常退出 Claude → 归档 → 保存旧登录 → 切换配置/登录快照 → 合并记录 → 重开 Claude。

Claude Desktop 在启动时读取推理配置，因此这里是**自动重启切换**。不是运行中更换现有请求的账号或上游，也不会强杀任务。存在本地 Code 会话进程（包括可能空闲的进程）时，界面先提示确认。确认任务完成或可以暂停后，工具正常退出并等待进程结束再切换，不需要手动退出。Claude 拒绝退出或超过 20 秒未退出时不写入配置。

## 共享与保护范围

- 两个原生数据目录：`~/Library/Application Support/Claude` 和 `Claude-3p`。
- 写入目标按当前模式和 `lastKnownAccountUuid` 识别。身份尚未建立时不导入；同一账号存在多个组织目录、无法可靠确定当前组织时停止操作，不猜测目标。
- 共享 `claude-code-sessions/<account>/<organization>/local_<uuid>.json` 中的本地 Code 记录。会话正文沿用同一台 Mac 上的 `~/.claude/projects/*/<cliSessionId>.jsonl`，不会移动或覆写正文。
- 不覆盖目标账户已有的同 ID 记录；同一记录的不同版本在归档中分别保留。目标目录有 `deleted_<uuid>` 标记时不重新加入。
- 跨账号复制仅保留标题、项目路径、模型、会话 ID、时间和基础状态。权限模式重置为默认；旧账号的 MCP 凭据、审批、自动远程控制状态不复制。
- 仅在正文存在时导入；缺少正文的记录保留在列表中并标记。备份 JSONL 只收录完整换行前缀。
- 云端会话、SSH、Cowork、云端项目、跨设备同步，以及收藏/侧栏分组不在当前同步范围。归档不是完整项目工作目录备份。
- 已存在记录的标题/归档状态不会跨账户互相覆盖；此版本进行增量补齐，不做破坏性镜像。
- 各模式已有会话的模型选择分别保留。首次导入后，如果原模型不在目标账号订阅或 API 的可用范围内，需要在 Claude 中选择可用模型再续聊。
- 官方账号快照包括 Electron 的 Cookies、本地存储和加密 token cache。只用于这台 Mac、同一系统用户；不导出或迁移系统钥匙串。不要在 Claude 中注销后期待被服务端撤销的登录仍能复用。
- 用量查询从当前官方登录或已校验的账号快照读取 Code 凭据，在内存中解密；仅向固定的 `https://api.anthropic.com/api/oauth/usage` 发起读取请求，拒绝重定向。不刷新/改写登录 token，不将凭据存入用量缓存，不通过第三方 API 查询官方额度。此接口属于客户端内部接口，未来变化可能需要更新适配。
- MDM 或组织下发的配置不被覆盖。Claude 原生数据写入仅适配已核验的 **4.29.0**；其他版本仍可查看、归档和编辑工具内的别名，需更新适配后才能修改 Claude 配置。

## 数据与恢复

工具数据位于 `~/Library/Application Support/SyncClaude/`：

| 路径 | 内容 |
| --- | --- |
| `history/records` | 按 SHA-256 保存的记录版本 |
| `history/transcripts` | 按 SHA-256 保存的主会话正文版本 |
| `accounts` | 本机官方登录快照，每个快照包含校验清单 |
| `accounts.json` | 账号名称、身份与快照索引，无明文 API Key |
| `aliases.json` | 按配置类型和稳定 ID 保存的显示别名 |
| `backups` | 每次切换的修改前副本、恢复副本与事务清单 |
| `pending.json` | 未完成事务的恢复日志 |
| `pending-purge.json` | 未完成永久清除的路径、哈希和索引更新清单，不含待删除文件的正文 |
| `removed-records` | 已清理账户目录的完整恢复副本及索引 |
| `usage.json` | 官方用量、重置时间和最近查询状态，无登录凭据 |

目录限制为当前用户访问，文件为 `0600`。切换前生成可校验备份，采用进程内外互斥与写入前日志；失败时回滚，崩溃后可点击 **恢复未完成操作**。备份保留原有登录信息和对话内容，应作为私密数据保管。此版本不自动清理历史版本，长期使用请关注占用。

**账户目录清理与恢复的规则**：有内容的目录清理前先归档并复制恢复副本，再移除原目录。副本没有自动到期时间，用户可手动永久清除；恢复必须通过内容校验，且原目录尚未重新建立，否则拒绝覆盖。恢复成功后，该目录转到“已恢复的备份”中，可直接清除旧副本而不影响已经恢复的原目录。各页按账户/组织区分，清除时包含该目录以前的所有恢复版本。共享会话正文、历史归档以及其他账号中的同一会话保留，后续同步可能再次补入会话。没有自动到期清理，也不承诺释放所有历史占用。

永久清除以文件为单位校验后删除，中断时不会回滚或生成数据副本。主界面会显示 **继续永久清除**，重试跳过已完成步骤；若文件出现新内容则停止，避免覆盖或删除新增内容。清除未完成时暂停其他写入操作。该功能是文件删除，不提供 SSD 物理安全擦除、系统快照或外部备份清除保证。

`accounts.json` 还记录用户主动删除的官方账号 ID，仅用于阻止自动快照和用量发现重新加入该账号；不包含该账号登录凭据。重新添加并明确保存该账号时清除对应标记。

不要在操作过程中手动启动另一实例 Claude，也不要让 CC Switch 同时写入配置库。读取现有 CC Switch 配置兼容；若其配置依赖本地路由，仍需让 CC Switch 路由服务运行。

## 构建与验证

需要 macOS 13+ 和 Xcode/Swift 5.9+。当前本机产物为 Apple Silicon。

```sh
swift test
zsh scripts/build-app.sh
```

构建结果：`dist/Sync Claude.app`。默认本地构建使用 ad-hoc 签名；设置 `SIGNING_IDENTITY` 可启用 Developer ID 签名与 Hardened Runtime。公证和发行步骤见 [发布说明](docs/releasing.md)。GitHub Actions 运行测试和默认构建，不包含签名凭据。

本地诊断和归档命令：

```sh
"dist/Sync Claude.app/Contents/MacOS/SyncClaude" --status
"dist/Sync Claude.app/Contents/MacOS/SyncClaude" --archive
"dist/Sync Claude.app/Contents/MacOS/SyncClaude" --self-test-keychain
"dist/Sync Claude.app/Contents/MacOS/SyncClaude" --purge-empty-recovery
```

`--status` 包含本机项目路径和标题，应仅用于本地诊断。不会输出 API Key、登录 token 或完整 API 地址。Keychain 自测只创建并立即删除随机测试凭据。

`--purge-empty-recovery` 默认只预览，没有删除副作用。核对结果后，追加 `--confirm-fingerprint <预览返回的 fingerprint>` 才执行；范围或内容变化会拒绝执行。此命令只接受经实际文件检查完全为空的恢复项及关联旧副本，非空项请在界面逐项确认。

实现依据与已知边界见 [调研记录](docs/research.md)，验收结果见 [验证记录](docs/validation.md)。
