# v0.1.2 已删除会话永久清理验证

日期：2026-10-29。开发机：macOS Apple Silicon、Claude Desktop 4.4212.0；本机已安装 Sync Claude 0.1.2 (4)。签名公证后的安装包随 [v0.1.2 Release](https://github.com/Chiiz0/Sync-Claude/releases/tag/v0.1.2) 分发。

## 行为与范围

“已删除会话…”按具体标题和项目列出仍有保留内容的会话，同时显示删除时间、账号记录、元数据归档、正文/附件及备份数量。单纯的删除标记不会作为有内容的会话显示。

选择会话后，预览展示分类文件数、逻辑字节数、完整路径及要更新的索引数量。确认复选框默认关闭，勾选前永久清理按钮禁用；取消不会删除文件。查看预览期间暂停后台归档。

确认后正常退出 Claude，再次核对预览指纹，逐文件校验后删除：本机 JSONL、该会话专属附件/子任务目录、工具元数据与正文归档、账户恢复副本和旧操作备份中的相关记录。其他会话引用同一正文时阻止操作；若关联会话也已删除，可一并选择。其他会话、登录/API 配置、项目源码和系统/手工外部备份保留。

执行不生成待删内容的备份。中断后保留仅含路径、哈希与剩余索引的执行清单，通过“继续永久清除”续做；拒绝覆盖新内容。部分清理账户恢复副本后更新其校验值，使其他会话仍能恢复。保留会话 ID 与删除时间，阻止旧记录重新导入，不承诺物理介质安全擦除。

## 测试

- 两种适配版本参数（4.29.0、4.4212.0）各 **89 项 XCTest，0 失败**。
- 新增 8 项测试覆盖：仅归档记录的只读预览；正文/附件/归档/所有相关操作副本清理；其他记录恢复；当前和归档中的共享正文引用；预览过期、活动任务与未知版本保护；中断续做及禁止归档；新文件、新引用、范围外执行清单；符号链接和损坏归档保护。
- 实机只读扫描 10 条已删除会话，预览 158 个文件、88,415,694 字节。逐文件哈希核对确认预览、勾选与取消后所有文件保持不变。
- 原生界面核验：单条会话展示 4 个归档文件、659 KB；可展开查看路径；确认默认禁用，勾选后启用，取消后返回列表，再次打开时确认状态重置。
- 真实用户数据没有执行永久清理。删除和中断续做使用隔离夹具完成；不能将其当作实机真实数据的删除验收。
