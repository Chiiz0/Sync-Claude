# v0.1.1 本机验证记录

日期：2026-10-29。环境：macOS Apple Silicon、Claude Desktop **4.4212.0**、Sync Claude **0.1.1 (3)**。本版本已在开发机安装验证，签名公证后的安装包随 [v0.1.1 Release](https://github.com/Chiiz0/Sync-Claude/releases/tag/v0.1.1) 分发。本机账号信息、登录数据、会话正文和原始诊断证据不随源码发布。

## Claude 升级适配

对照已验证的 4.29.0 与当前安装包，确认本地官方/API 数据隔离、原生配置库、Code 会话路径和删除标记、共享 JSONL、登录快照、用量查询以及 1M 模型偏好的格式仍匹配。版本校验统一为精确白名单 `4.29.0`、`4.4212.0`；未知版本继续允许只读归档，拒绝原生写入及登录凭据读取。

## 尊重用户删除

仅把原生有效的 `deleted_<uuid>` 时间戳视为删除依据，不根据文件缺失、退出登录或清理账号目录推断删除。工具保留仅含会话 ID 和时间戳的删除索引。

- 刷新或后台归档后，任一账号已删除的会话从工具列表隐藏；待移除的其他账号副本显示计数。
- 同步或切换时正常退出 Claude，备份并移除这些元数据副本，同时补入原生删除标记。
- 旧归档、账号目录恢复以及后续切换都不会重新导入已删除会话。
- 共享 JSONL、归档版本与操作备份保留。这是会话列表删除同步，不是永久擦除正文。

实机已有 10 条带明确删除标记的历史会话仍出现在工具列表。新版本先将其隐藏；其中 9 条各有 1 份残留元数据，另 1 条只剩工具归档、原生目录已无副本，因此同步实际移除 9 份。隐藏按独立会话计数，移除按原生文件副本计数，两者不必相等。同步后官方和 API 均保留 4 条有效会话（2 条原记录、2 条本次验证记录），再往返切换没有重新导入已删除记录，待删除副本数为 0。

操作前保存文件清单、内容副本及 SHA-256。首次删除同步核验：实际移除路径与预期 9 份完全一致；保留会话元数据、原生旧删除标记和原归档文件均未改动；共享正文未被重写。唯一追加发生在本次测试会话正常退出时，为 Claude 自己写入的 `last-prompt` 与 `cost-state` 行。没有未完成恢复或清除操作。
