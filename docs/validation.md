# v0.1.0 验证记录

日期：2026-10-29。实机环境：macOS Apple Silicon、Claude Desktop 4.29.0。下面区分真实客户端验证、隔离测试和未覆盖范围；本机账号数据、会话正文及诊断日志不随源码或安装包发布。

## 自动化与构建

- **71 项 XCTest，0 失败**，覆盖记录增量合并、身份/组织定位、快照切换、事务回滚、崩溃恢复、用量解析与失败缓存、1M 默认修复、别名、配置删除、目录清理/恢复及永久清除中断续做。
- Release 模式编译、应用打包和 `codesign --verify --deep --strict` 校验通过。
- 预编译包为 arm64。macOS 13 是声明的最低系统版本，未在每个 macOS 版本逐一验收。

## 实机验证

| 功能 | 已观察的结果 |
| --- | --- |
| API 请求与重开续聊 | Claude Code 收到真实网关回复；工具正常重开后可继续原会话 |
| 官方/API 往返 | 已登录官方账号导入原 API 记录，打开并成功续聊；切回 API 后继续同一会话，能复述官方阶段的回复；JSONL 和 `cliSessionId` 连续 |
| 历史保护 | 原有记录哈希保持不变；客户端产生的焦点时间或正常退出追加内容单独核验，未当作工具改写正文 |
| 官方用量 | 一个真实官方账号通过固定 Anthropic 接口返回 HTTP 200，原生面板显示用量与重置时间 |
| 默认 1M | 未手动选模型的新会话使用 `[1m]` 模型并显示 1M 窗口，短请求成功；工具修复旧偏好后保留其他配置 |
| 官方账号入口 | 侧栏仅显示真实保存账号，统一为“添加官方账号”与“切换到此账号” |
| 别名 | 官方/API 中文别名保存、重开后保留、恢复原名称；侧栏及用量面板显示正确 |
| 配置删除 | 原生菜单、当前配置保护、确认及取消流程通过；实际配置删除由隔离测试覆盖，没有为验收删除真实配置 |
| 目录清理与恢复 | 旧空目录清理、恢复后的文件哈希核验及再次清理通过 |
| 永久清除 | 原生单项/批量预览与确认范围核验；通过安装后的 CLI 使用匹配指纹实际清除空恢复副本和关联旧备份，未新增备份，保留共享正文、配置和登录快照 |

菜单栏别名使用同一数据绑定，未单独打开菜单栏验收。永久清除的实际删除通过 CLI 执行，原生确认框核验后取消，两者使用相同核心实现。

## 未覆盖范围

- 第二个真实官方账号的用量查询、真实官方账号 A → B → A，以及快照恢复后的免登录体验；相关核心路径已用隔离夹具验证。
- 新录入真实 API Key 经 credential helper 首次授权到实际推理的完整流程；钥匙串存取已本机测试。
- 另一台物理机器首次安装、Intel Mac，以及不同 macOS 版本矩阵。
- 接近 1M token 的请求容量或压力测试；当前结果只证明默认选择、窗口声明和短请求成功。
- 云端、Cowork、SSH、跨设备同步、多协议代理；这些不属于本版本功能范围。
