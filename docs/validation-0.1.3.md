# v0.1.3 本机验证（2026-10-30）

本记录覆盖 v0.1.3 的本机测试、安装与签名公证验收。

## 新会话错误的原因与复现

只读检查本机 Claude Desktop 4.4212.0：`registerHeldFirstStartSession` 在启动 CLI 前建立带 `pendingFirstStart.since/options` 的记录，尚无 `cliSessionId`；元数据序列化会省略未定义的字段。原生记录通常原子写入，但部分写入错误会降级为直接写入，因此同时考虑短暂读取竞争。

在隔离目录导出 v0.1.2 源码，放入符合上述格式的合成记录：原版 `status()` 和 `archive()` 均报告“不支持的 Code 记录格式”。修复版同一记录可被查看，标记为“正在初始化”，不会写入可跨账户恢复的归档；补齐 CLI ID 和正文后可以归档与同步。没有在用户的真实会话目录注入测试记录。

JSON 短暂解析失败或文件移动，在 Claude 运行时最多读取三次；仍失败且文件刚修改时延后归档。权限错误、符号链接、无效 ID、未知占位格式及持续损坏不视为正常初始化。后台失败显示在底部，不反复弹窗；成功归档清除提示。

## 账号与更新

- 已保存的当前账号不可重复保存；核心重复调用也不产生新快照或重启。新登录仍需要首次保存；切换离开时自动更新已保存账号的登录快照。
- 别名、用量缓存与自动快照更新一并回归，替代旧的“重复保存来改名”测试。
- 更新检测使用 [GitHub 最新正式 Release 接口](https://docs.github.com/en/rest/releases/releases#get-the-latest-release)，固定仓库与 HTTPS Release 地址；无登录凭据和会话数据发送。数值比较版本，排除草稿/预发布，不提示降级。
- 自动检查默认开启，成功后 24 小时内不自动重复；失败至少退避一小时。设置、检查时间和已验证的版本结果跨启动保留；支持立即检查和跳转下载，不自动替换应用。
