# 已有会话状态同步审查

审查日期：2026-11-12。范围：[PR #4](https://github.com/Chiiz0/Sync-Claude/pull/4) 的归档状态、会话层级、正文接续及同步基线生命周期。

## 复现与修复

原始 PR 的 182 项测试通过，但补充的三个场景均可复现问题：

- 新账号尚无目标记录时，即使历史链中的正文缺失，也会导入最新正文指向。
- 新账号导入时，已知祖先记录的项目路径与接续记录不同，仍会导入。
- 顶层会话已经建立同步基线后，新发现的两个旧目录若保留不同父关系，旧层级恢复器仍会在字段合并前报冲突，阻断账号切换。

修复把历史正文存在性和已知祖先项目路径校验用于新导入、正文指向推进，以及同一正文指向下的历史链补齐。校验失败时停止操作，由原事务恢复账号、会话及基线。

已有基线的会话不再调用首次迁移用的层级恢复器。层级由基线和可识别的字段修改决定；新副本仍保留可迁移的显示名称，继续过滤执行状态和权限。
